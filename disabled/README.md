# disabled/

이 디렉터리의 레코드는 **비활성화되어 있다.** DNS로 게시되지 않는다.

동기화 스크립트(`.github/scripts/sync-pdns-dns.ts`)는 `records/`만 읽는다.
따라서 여기로 옮겨진 이름은 존에서 제거되고 해석되지 않는다.

## 삭제가 아니다

파일은 그대로 남아 있고, 되돌리는 것은 `records/`로 다시 옮기는 것뿐이다.

```
git mv disabled/<name>.json records/<name>.json
```

## 이의 제기

비활성화가 잘못됐다고 생각하면 알려주면 된다. 되돌린다.
연락처는 저장소 루트 `README.md`에 있다.

우리 판단이 틀릴 수 있다는 전제로 운영한다. **애매하면 통과가 기본값이고,**
비활성화는 되돌릴 수 있는 형태로만 한다.
